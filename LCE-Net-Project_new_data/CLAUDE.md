# Working style for this project

- Make reasonable decisions yourself and carry the task through to the end. Do not stop to ask clarifying questions unless the task is genuinely blocked (missing file, missing access, or a choice only the user can make).
- When you make a judgment call, state it briefly in your final message so the user can redirect you.
- If a step fails, try a reasonable fix before reporting it.
- Keep changes to the files the task needs. Do not delete or overwrite checkpoints, datasets, or result files without looking at them first.
- Report results faithfully: include the actual numbers and say when something did not work.
